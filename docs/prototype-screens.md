# 主要画面のプレビューと編集ガイド

## 起動と確認

```sh
pnpm install
pnpm dev --port 3001
```

ブラウザで http://localhost:3001/preview を開きます。プレビューにはバックエンド、OAuthログイン、APIキーが不要です。既存のGoogle Fontsは初回起動・ビルド時に取得されるため、インターネット接続が必要です。

- **初回フローを試す**：設定 → プリセット選択 → 初会話 → 家。
- **体験済み状態で開く**：レベル2、思い出3件、未振り返り会話1件、参加中のデモイベントとカード3枚を用意します。
- **確認メニュー**：現在の変更を引き継いで画面を選べます。
- **初期化**：プレビューのデータを初回状態に戻します。体験済み状態への切り替えも、それまでの変更を置き換えます。

保存先は `sessionStorage` の `kasagichat:prototype:v1:preview`。通常画面は `kasagichat:prototype:v1:app` を使います。タブを閉じると保存内容は失われます。ストレージが利用できない場合は、案内を表示してメモリ内で続行します。壊れた／異なるバージョンの保存データは初期化します。

## 画面と導線

通常URLの先頭に `/preview` を付けると、同じ表示部品を使うプレビューになります。

| 通常URL                  | 内容                                                                       |
| ------------------------ | -------------------------------------------------------------------------- |
| `/home`                  | 分身、今日のひとこと、成長、思い出、プロフィール、アルバム、未振り返り会話 |
| `/settings`              | プロバイダ、ダミー設定の登録／削除、口調サンプルON/OFF                     |
| `/onboarding`            | 分身選択と初会話。6往復で入力終了、3往復から振り返り可能                   |
| `/map`                   | 既存Three.jsの街、5スポット選択、練習3シーンの会話                         |
| `/events`・`/events/new` | イベント一覧、招待コード入力、作成フォーム                                 |
| `/events/[eventId]`      | 会場、参加者、受信カード、招待コード／URL／QR                              |
| `/join/[code]`           | 参加確認。未準備なら設定・分身誕生後に戻る                                 |
| `/cards/[cardId]`        | 開封演出、保存した会話報告、最初に話しかける質問                           |

常設デモの招待コードは **HOSHI26**。会場は `/preview/events/hoshikawa`、参加後のカード例は `/preview/cards/hoshikawa-haru` です。

招待・カードはスマホ幅に対応しています。マップは768px未満でPC利用の案内を表示します。会話パネルを開いている間はマップの描画更新と入力を停止し、閉じると再開します。スポットは建物クリックでも下部のボタンでも選択できます。歩行、エディタ、旧描画比較、保存マップ読み込みはありません。

通常画面は既存のSpring認証判定を利用します。登録済みユーザーを常に家へ戻していた処理を修正し、追加画面への移動を許可しました。認証確認に失敗した保護画面は503を返します。未ログインの招待アクセスは、限定した内部パスをHttpOnly Cookieに保持し、OAuth・初回登録後に参加ページへ戻します。プレビューのURLはproxyの対象外です。

## 調整する場所

| 変更したい内容                                                    | 主なファイル                                                                                            |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 文言、相棒画像、参加者、会話の定型応答、初期データ、EXPと待ち時間 | `src/features/prototype/fixtures.ts`                                                                    |
| 状態と操作の型                                                    | `src/features/prototype/types.ts`                                                                       |
| 会話・成長・イベント・カードの状態遷移                            | `src/features/prototype/service.ts`                                                                     |
| 保存先、復元、Reactへの通知                                       | `src/features/prototype/store.tsx`                                                                      |
| ヘッダー、ナビゲーション、プレビュー表示                          | `src/features/prototype/shell.tsx`                                                                      |
| 通常／プレビュールートからの画面選択、初回準備の案内              | `src/features/prototype/screens.tsx`                                                                    |
| 家、設定／誕生、会話、マップ、イベント、カード                    | 同ディレクトリの `home.tsx`、`onboarding.tsx`、`conversation.tsx`、`map.tsx`、`events.tsx`、`cards.tsx` |
| 共通パネル、見出し、アバター、リンク、dialog                      | `src/features/prototype/ui.tsx`                                                                         |
| 街の床と建物の配置                                                | `public/assets/maps/hoshikawa-town.json`                                                                |
| Three.js描画と座標変換                                            | `src/components/map/`                                                                                   |

色・角丸・余白はdaisyUIとTailwindのクラスで調整します。テーマは既存の切り替えを利用します。画像を差し替えるときは `fixtures.ts` のパスを変更し、家・会話・マップの両方のサイズで確認してください。新しい素材生成や既存画像の加工はしていません。

`service.ts` は副作用のないreducerです。UIは `dispatch` に「会話を開始する」「振り返る」などの操作を渡します。API接続時はこの境界を非同期サービスに置き換え、サーバから返された状態をstoreに反映する形にします。クライアントの成長計算、定型応答、サンプル参加者を本番の判定に流用しないでください。

振り返りは会話ID、送信は期待する往復数、参加とカード開封は対象IDを確認し、同じ操作の重複反映を防ぎます。自動で会話や振り返りを実行せず、ボタン操作を起点にしています。

## モックの境界

- APIキー欄は編集できないダミー値です。実キーの入力、送信、保存は行いません。
- 会話・振り返り・共通点・カード報告は固定サンプルです。入力内容をAIへ送る処理や実マッチングはありません。
- 口調サンプル設定は保持しますが、定型応答の文面は変わりません。
- 作成イベントは同じタブ内だけで確認できます。QRは実際の招待URLをローカル生成しますが、別端末へのデータ共有はAPI接続後の機能です。常設デモイベントは各タブに初期データとして存在します。
- 家の思い出は簡易アイコン、イベント会場は既存NPC画像を並べたDOMです。本番向けの素材、演出、DB/API設計は別作業です。
- 認証済み通常画面も、認証以外はモックです。OAuthの実ログイン・実API・本番デプロイの動作保証とは分けて扱います。

## 検証

2026-09-13にlint・型チェック・12件の自動テスト・本番ビルドを実行しました。ブラウザでは初回／体験済みの切り替え、初会話の3往復と6往復、振り返り失敗と再試行、会話中断・復元、マップの会話オーバーレイ、プロフィール保存、イベント作成・参加、カード開封・復元、390px幅の参加・カード・マップ案内、Light/Dark表示を確認しています。通常URLの未ログイン時リダイレクトもHTTPで確認しました。実際のOAuthログイン完了試験と実AI/API連携は実施していません。

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

`pnpm format:prototype` で追加機能・マップ・テスト・このガイドを整形できます。`dev` はWindowsでも起動できるコマンドにしています。監視のポーリングが必要な環境では `WATCHPACK_POLLING=true` を環境変数として設定してください。

自動テストは初回フローの順序、往復数制限、再送・振り返り・参加・開封の重複防止、プロフィールの操作、保存データ復元、期間判定、認証リダイレクト、マップの読込／不正データを検証します。

画面変更後は、次の導線をブラウザで確認してください。

1. 初回状態から設定・分身選択・3往復で終了し、家に思い出とEXPが反映される。
2. 会話中にEscapeで閉じ、家から再開する。「プレビューの動作確認」で次の振り返りを失敗させ、再試行で一度だけ成長する。
3. 街の3シーン、プロフィールの保存・公開切り替え・削除、アルバムと成長履歴を開く。
4. イベントを作成し、招待コードとQRを確認する。HOSHI26から参加してカードを開き、再読み込み後も開封結果が残る。
5. 初期状態の空一覧、不正コード、存在しないイベント／カード、開催前・終了後を確認する。
6. マップ読込失敗時のメッセージと再読み込み、Light/Dark、スマホ幅の参加・カード、キーボード操作を確認する。
